# Дизайн: кнопка СТОП/СТАРТ для остановки сборки новостей

## Задача

Добавить в админ-меню (`/admin`) кнопку, которая ставит на паузу автоматическую сборку новостей. Кнопка должна динамически переключаться между состояниями СТОП (когда бот активен) и СТАРТ (когда остановлен).

## Требования

1. Кнопка отображается в нижней части меню `/admin`.
2. Текст и `callback_data` зависят от текущего состояния:
   - Активен → `⏸ СТОП` (нажатие останавливает планировщик).
   - Остановлен → `▶️ СТАРТ` (нажатие возобновляет планировщик).
3. Команда `/post` (ручной запуск сводки) работает всегда — независимо от состояния СТОП/СТАРТ.
4. Состояние сохраняется в БД — после рестарта контейнера/сервера бот остаётся в том же режиме.
5. Деплой только через `git push` в `main`. CI/CD на GitHub собирает и доставляет на сервер; локально ничего запускать не нужно.

## Архитектура

### Состояние

Используется существующая таблица `settings` (ключ-значение, доступ через `get_setting` / `set_setting` в `bot/cursor/manager.py`). Новый ключ:

| Ключ | Значения | Дефолт | Описание |
|------|----------|--------|----------|
| `bot_active` | `"1"` / `"0"` | `"1"` | Активна ли автоматическая сборка новостей |

Никаких миграций не нужно — `get_setting` возвращает дефолт, если ключа нет.

### Управление планировщиком

Используются нативные методы APScheduler:
- `scheduler.pause_job("news_cycle")` — заморозить job (триггер сохраняется, выполнение останавливается).
- `scheduler.resume_job("news_cycle")` — снять с паузы.

Доступ к scheduler — через singleton `bot.state.get_scheduler()` (уже есть).

### Поток выполнения

**При нажатии «СТОП»:**
1. `set_setting("bot_active", "0")`
2. `scheduler.pause_job("news_cycle")` (с try/except — на случай если job отсутствует).
3. Перерисовать меню — кнопка теперь показывает «СТАРТ».
4. Показать `callback.answer("Бот остановлен", show_alert=True)`.

**При нажатии «СТАРТ»:**
1. `set_setting("bot_active", "1")`
2. `scheduler.resume_job("news_cycle")` (с try/except).
3. Перерисовать меню — кнопка теперь показывает «СТОП».
4. Показать `callback.answer("Бот запущен", show_alert=True)`.

**При старте бота (`bot/main.py`):**
1. `scheduler.add_job(...)` (как сейчас).
2. `scheduler.start()` (как сейчас).
3. **Новое:** если `get_setting("bot_active", "1") == "0"` — вызвать `scheduler.pause_job("news_cycle")` и залогировать `Bot loaded in STOPPED state`.

## Изменения в коде

### `bot/admin/router.py`

1. **`_admin_kb()` становится async-функцией** и читает `bot_active`. Возвращаемая клавиатура:
   - Существующие кнопки в том же порядке.
   - В конец добавляется ряд с кнопкой `⏸ СТОП` или `▶️ СТАРТ`.

2. **Все вызовы `_admin_kb()` заменяются на `await _admin_kb()`** (≈10 мест).

3. **Два новых callback-обработчика:**
   - `cb_bot_stop` (на `F.data == "bot_stop"`)
   - `cb_bot_start` (на `F.data == "bot_start"`)

   Оба перерисовывают сообщение `/admin` с обновлённой клавиатурой.

### `bot/main.py`

После `scheduler.start()` — проверка флага и `pause_job` при необходимости. Импорт `get_setting` уже есть.

### Что НЕ меняется

- `bot/main.py:run_cycle` — без изменений.
- `bot/state.py` — без изменений.
- Логика `/post`, reset_cursor, interval, news_count, topics, stopwords — без изменений.
- Структура БД — без миграций.

## Тестирование (вручную после деплоя)

1. `/admin` → кнопка «⏸ СТОП» внизу.
2. Нажать «⏸ СТОП» → alert «Бот остановлен», кнопка меняется на «▶️ СТАРТ», авто-сводки прекращаются.
3. `/post` всё ещё работает (ручная сводка приходит).
4. Нажать «▶️ СТАРТ» → alert «Бот запущен», кнопка снова «⏸ СТОП», авто-сводки возобновляются.
5. Перезапуск контейнера в режиме СТОП → бот остаётся в режиме СТОП после старта.

## Деплой

1. Локально: коммит + `git push origin main`.
2. CI/CD на GitHub собирает Docker-образ и доставляет на сервер.
3. На сервере `docker-compose up` (или эквивалент в CI/CD) подхватывает новый образ.
4. Существующий `data/bot.db` совместим — никаких миграций.

## Откат

В случае проблемы — `git revert` коммита и снова `git push`. БД не трогается, ключ `bot_active` остаётся в settings, но больше не используется.
